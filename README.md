## About Me

I'm a software engineer based in Pakistan with **6+ years of experience** building multi-tenant SaaS platforms, business applications, and high-performance backend systems.

As **Co-Founder of [Boson Studio](https://www.bosonstudio.com)**, I work directly with businesses to turn complex requirements into practical, maintainable software.

My strongest expertise is in **PHP and Laravel**, supported by frontend experience with **Vue.js, React, and Angular**. I take ownership across the product lifecycle: requirements, architecture, implementation, testing, deployment, and production support.

I'm also building AI-powered applications using **Laravel AI SDK, LLM APIs, tool calling, and retrieval-augmented generation**.

**Stack:** Laravel · Vue.js · Nuxt.js · MySQL · AWS

[Visit platform →](http://tripvlog.com)

**Stack:** React · Vite · Zustand · Tailwind CSS · hls.js · Laravel API
